# Claude Bridge — releases

Versiones publicadas de Claude Bridge, el panel para usar Claude Code adentro de Adobe Premiere Pro.

- **Windows:** [ClaudeBridge-Windows.zip](https://github.com/Gonav-maker/ClaudeBridge-releases/releases/latest/download/ClaudeBridge-Windows.zip) → descomprimir → doble clic en `Instalar.cmd`.
- **Mac:** [ClaudeBridge-Mac.zip](https://github.com/Gonav-maker/ClaudeBridge-releases/releases/latest/download/ClaudeBridge-Mac.zip) → `ClaudeBridge/install.sh`.

Después, en Premiere: Ventana → Extensiones → Claude Bridge. El panel se actualiza solo.
